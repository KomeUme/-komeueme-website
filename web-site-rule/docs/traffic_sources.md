# 流入元URL

名刺とInstagramでは、以下のURLを使い分ける。

## 名刺

`https://komeueme-website.pages.dev/?utm_source=business_card&utm_medium=print&utm_campaign=portfolio`

## Instagram

`https://komeueme-website.pages.dev/?utm_source=instagram&utm_medium=social&utm_campaign=profile`

UTMはURLの識別情報であり、単独では集計機能を持たない。アクセス解析を導入する場合は、プライバシーポリシーの記載と実際の収集内容を一致させる。
